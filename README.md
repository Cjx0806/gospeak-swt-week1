## V20：逐句学 → 连句说 → 随机答

24 类真实口测话题使用同一套短句，通常每句 3—8 个词、每答 2—4 句（完整校名除外）。句子课和口测主线共享句子、词义、音标、语法、示范音和逐句录音入口，不必另背一套长稿。原 14 天句子课和已有本机记录保留在次要入口；原连续听练标为拓展材料，不冒充这次简化短句。

1. 「逐句精学」：慢速听、跟读，展开看单词中文/音标/结构；点「开始跟读录音」。
2. 「连成回答」：原句从第 1 句累加到整段，再录一遍。
3. 「随机口测」：隐藏答案，听同义问法或独立追问，用简单真实的短句回答。卡住可查看思路。

录音前主动勾选「识别我说的英文」。首次默认关闭；同意后仅本次页面记住，切换句子不必反复勾选，取消即关闭，刷新重置。每次仍需手动点录音，不会自动开麦。

逐句/连句显示 **跟读文字匹配分 /100**、一致识别词、需要回听复核词及最多 5 个重点词试听。该分数不等于专业发音或机构口测分；识别差异不证明发音错误。无最终识别文字、识别服务中断、手动文字均不评分。随机回答不按范文逐字扣分，保留录音、转写和自查提示。用户已确认其 iPad 原句子课识别与评分可用；本次仍需在其实际 Safari 上验收新入口。

隐私：录音由用户主动授权，只存本机，本站无接收录音的后端；选择语音识别后浏览器可能将语音交给其语音服务。精确音素评分需要不同的专业服务，本版没有暗接新服务或密钥。参考：[MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)、[微软发音评估说明](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/how-to-pronunciation-assessment)。

播放继续保留单播放器互斥、加载超时、恢复声音和麦克风等待取消；不批量预载全日音频。页面每次仅初始化一个新录音组件，保存中不切题。全站保留上限仍为 18 条、每练习 3 条（界面提示），重要录音请下载；更新本身不清除进度。

## 今天怎么学

1. 用 iPad Safari 打开「SWT口测主线」。自我介绍已会，不必从头重背；先学默认题「为什么参加 SWT」。
2. 听英文问题，展开短答案。每句话可看中文、音标、意群、句子成分和单词，点慢速或正常示范。
3. 逐句跟读后，用累加串句把句子连起来：第一句 → 前两句 → 整段。每个阶段都有本地录音入口。
4. 同题练三遍：看中英 → 只看关键词 → 隐藏答案。每天最多记五个表达缺口，次日复测。
5. 练习随机问法、追问和五题小模拟。听过不算掌握，最后必须有脱稿口头输出。

主线包含24类问题，包括动机、岗位、证书、沟通困难、错误与冲突、优缺点、文化差异和回国安排。未知的经历使用明确的条件分支，不替学习者编造兼职、旅行、游泳距离或家庭支持。方括号待填内容禁止作为范文播放。

14天安排是从本机首次使用日起轮转的学习建议，不是虚构的面试倒计时。具体口测和返校日期均尚未确定。新概念英语第一册保留原视频与目录，作为基础补充；考前不以赶完全册为目标。

## 连续听练

- 14课，三种模式：教学精听、纯英文复习、模拟口测。
- 教学精听每句：英文一次 → 中文一次 → 英文三次并留跟读空白；末尾练整段。
- 点击一次即可播放预先生成的完整 MP3，可从某课开始、调速、循环和下载。
- 显示当前英文与中文；可收起中文或打开跟随字幕。整段示范对应整段文本，不伪造逐词对齐。
- 美式英语 Emma Neural、中文晓晓，均为合成语音，非真人录音。

后台和锁屏播放取决于设备、iPadOS和网络，不能保证所有设备不中断。弱网可下载音频到本机播放器。不要在救生员值班、游泳中或需要听清环境时分心听课；设备远离水。

## 录音和隐私

- 麦克风必须由学习者主动点击并授权；网页不自动录音。
- 默认录音仅保存在该设备浏览器的 IndexedDB；每个练习最多3条、全站最多18条，界面说明滚动保留规则。可以回放和下载，清除浏览器数据会丢失本地记录。
- 本地提示包括录音时长、音量和复听检查；它们不是口语水平或音素评分。
- 可选的浏览器语音识别必须另行主动开启，可能由浏览器厂商联网处理。文字差异仅帮助检查漏读或错读，不能判断每个音是否标准；Safari及大陆网络的可用性需实际测试。
- 生成静态语音前，学习者已明确同意将课程文字发送到微软 Edge 在线语音合成服务；照片、证件和个人录音未用于合成。

## 发布与维护

为了在 GitHub 网页上传限制内发布，V19 使用四个基础 ZIP 和一个缓存升级包：

- `gospeak-v19-site.zip`：完整静态站点，含逐句/单词新音频，不含连续长音频。
- `gospeak-v19-listening-modules.zip`：42条单课长音轨与音频清单。
- `gospeak-v19-listening-collections.zip`：3条全集长音轨。
- `gospeak-v19-source.zip`：可审阅的 `assets/` 和 `scripts/`。
- `gospeak-v19-update.zip`：最后解压到仓库根目录的缓存兼容补丁，更新 `_site/` 与可审阅源文件；不重复存放音频。

工作流只解压、校验和部署，不在发布服务器上重新调用语音合成服务。原版本文件留作历史，不是当前活动课程。

本地修改步骤（Python 3.10+；mutagen 1.48.1）：解压站点和音频到 `_site`，解压源代码到仓库根目录。已有音频时运行：

```sh
python scripts/build_v18_listening.py _site --skip-audio
python scripts/build_v19.py _site --skip-audio
python scripts/verify_v19.py _site
node scripts/test_recorder_v19.cjs
node scripts/test_recorder_lifecycle_v19.cjs
node scripts/test_mainline_v19.cjs
python scripts/package_v19.py
```

需要新增语音时另需 `edge-tts==7.2.8`、FFmpeg及相应课程文字外发许可，再去掉 `--skip-audio`。连续音轨先解码到 PCM 拼接，字幕时间按真实音频样本计数，避免 MP3 编码填充造成长期漂移。缓存按内容哈希区分。

Service Worker不拦截音频或 Range 请求，保留原生拖动进度能力。GitHub Pages在不同大陆网络下的连通性可能不同；不承诺任意网络均可访问。
