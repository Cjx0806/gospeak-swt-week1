# GoSpeak SWT V18 连续听练

无需 GPT 登录的独立英语学习站。保留 V17 句子课、单词点读和口测主线，新增 14 个 SWT 口测音频模块。

网站：https://cjx0806.github.io/gospeak-swt-week1/?v=18

## 在 iPad 上开始

1. 用 Safari 打开网站，进入「月底口测主线」顶部的「连续听练」。
2. 选「教学精听」，点「一键连续播放 · 全 14 课」。点击一次后播放整条预合成长音轨，不需要逐句操作。
3. 熟悉意思后用「纯英文复习」练连贯表达；有空开口时用「模拟口测」。
4. 可以从指定课程开始，或只听一课；可调播放速度、循环当前音轨、暂停、继续上次进度。
5. 网络不稳定时下载整条 MP3 到自己的设备，用支持本地音频的播放器打开。下载不等于网页自动离线缓存。

## 三种模式

- **教学精听**：每句英文一次 → 中文一次 → 英文慢速、标准、自然语速各一次。后面三遍均留跟读空白；每课最后再听整段回答的三种语速。
- **纯英文复习**：英文问题一次 → 整段慢速、标准、自然语速各一次。没有中文，不重复整套逐句教学。
- **模拟口测**：英文问题 → 3 秒准备 → 开始提示 → 30 秒自行回答 → 自然语速参考答案。此模式不自动录音或评分。

声音为预生成的美式英语 Emma Neural、中文晓晓合成语音，不是真人录音。听过不等于能说：建议每天至少脱稿回答一题并录音。

## 内容与使用边界

- 真实资料沿用本人确认的学校、年级、体育体能训练专业、中国救生员证及学习目标；情景题使用假设回答，不编造工作或旅行经历。
- 学校、姓名和专业英文如与报名材料不同，应以本人材料为准。
- 口测月份以当前需求为准；页面的月底时间不是已确认的具体面试日期。
- iPad 需要首次手动点击播放。后台、锁屏和下载后的播放行为取决于 iPadOS、浏览器、播放器和网络，不能保证在所有设备上不中断。
- 不需要 GPT 或 VPN 登录，但 GitHub Pages 在不同大陆网络的连通性可能不同。
- 不要在救生员值班、需要听清环境或其他高风险活动时分心听课。设备远离水，游泳前后再练。

## 构建

GitHub Actions 保留原有 V17 构建，再解压已验证的 V18 音轨并校验全部 45 个 MP3。为兼容网页上传，源代码保存在 `gospeak-v18-source.zip`（仅 `assets/` 与 `scripts/`），音频分别保存在 `gospeak-v18-modules.zip` 与 `gospeak-v18-collections.zip`。解压源代码后即可审阅和运行；音频不依赖访问者实时调用 TTS。

重新生成音频需要 Python 3.10+、`edge-tts==7.2.8`、FFmpeg 和 ffprobe（或 `mutagen==1.48.1` 读取时长）。先按旧构建准备 V17 的 `_site`，再执行：

```sh
python scripts/build_v18_listening.py _site --jobs 4
```

14 × 3 条单课 MP3、3 条全集 MP3及双份同内容 JSON 清单在构建时生成。TTS 以语音、文本和语速的内容哈希缓存在 `.audio-cache-v18`。浏览器只请求静态 MP3，不在播放时调用 TTS 服务。清单包含时长和章节偏移，用于整轨跳转。

```sh
python scripts/build_v18_listening.py _site --skip-audio
```

`--skip-audio` 用于界面/接线测试。没有真实音频时标记 `built: false`，不会提供假播放。已有音频时只读取时长并刷新页面接线。

修改源代码或重新生成音频后，应重新打包对应的三个 ZIP。发布工作流会拒绝缺失或不可读的 MP3，验证成功后才部署。

Service Worker 不缓存 V18 MP3，也不拦截 Range 请求，以保留浏览器的分段加载和拖动进度能力。页面本地保存听练位置，不上传个人录音。
